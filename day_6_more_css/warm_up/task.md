# 🚀 Day 6 — Warm-Up Challenge (CSS Centering + Card Layout)

## 📌 Task Overview
This warm-up challenge was designed to:
- Build confidence before main Day-6 tasks
- Practice proper card structure (image + text + button)
- Master centering using **flexbox**
- Use **box shadows**, padding, and spacing correctly
- Improve readability & clean CSS habits

---

## 🎯 Requirements
### ✔ Warm-Up Card
- A centered card in the middle of page  
- Image at the top (full width, responsive)
- Title + paragraph text
- Clean button with border
- No padding applied to image area
- Smooth box-shadow (not too heavy)

### ✔ Flexbox Centering
- Entire card must be centered horizontally and vertically  
- Must use:
  - `display: flex;`
  - `justify-content: center;`
  - `align-items: center;`
  - Use `min-height: 100vh` (not height: 100vh)

---

## 🧱 Structure Requirements
### HTML
- Wrapper container (optional)
- Card div
- Image tag
- Title (h2)
- Paragraph
- Button

### CSS
- Responsive image: `width: 100%; height: auto;`
- Card width around **350–400px**
- Padding only inside text area
- Gap/spacing using margin
- Box-shadow with soft blur
- Rounded corners are optional
