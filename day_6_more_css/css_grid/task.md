# 📅 Day 6 — CSS Grid Practice  
### 🚀 My Dev Journey — 30 Days of Code  
### 🧩 Topic: CSS Grid (3 Practical Challenges)

---

## ✅ **Challenge 1 — 3 Column Equal Layout**
**Goal:**  
Create a 3-column grid with equal column width and fixed height boxes.

**Requirements:**
- Use `display: grid`
- Define columns using `grid-template-columns: repeat(3, 1fr);`
- Add spacing using `gap`
- Apply background colors to identify each box

**Status:** ✔ Completed  
**Concepts Learned:** `repeat()`, `1fr`, gaps, grid structure.

---

## ✅ **Challenge 2 — 2x2 Perfect Square Boxes**
**Goal:**  
Create 4 boxes that always remain perfect squares.

**Requirements:**
- Use a 2-column grid  
- Use `aspect-ratio: 1 / 1`  
- Use different background colors  
- Grid should stay responsive  

**Status:** ✔ Completed  
**Concepts Learned:**  
`aspect-ratio`, responsive grid sizing, fractional units.

---

## ✅ **Challenge 3 — Responsive Gallery Grid**
**Goal:**  
Create a responsive, Pinterest-style image gallery.

**Requirements:**
- Use `grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));`
- Add `gap: 20px`
- Use `object-fit: cover` for consistent image cropping
- Add image captions
- Works on all screen sizes  

**Status:** ✔ Completed  
**Concepts Learned:**  
`auto-fit`, `minmax()`, responsive layout techniques.

---

- `auto-fit` vs `auto-fill`  
- How aspect ratio works  
- How object-fit gives perfect cropping  
- Multi-grid layout on single page
