## 🧠 2. What I Learned Today

### 🔸 HTML Document Structure
- `<!DOCTYPE html>` declares HTML5  
- `<html>` wraps whole document  
- `<head>` holds metadata & title  
- `<body>` contains visible content  

### 🔸 Important HTML Elements Practiced
- **Headings:** `h1` → `h6`  
- **Paragraph:** `p`  
- **Lists:**  
  - Unordered: `ul`, `li`  
  - Ordered: `ol`, `li`  
  - Description: `dl`, `dt`, `dd`
- **Links:**  
  - Internal (`href="#skills"`)  
  - External (`target="_blank"`)
- **Images:** `img`  
- **Tables:** `table`, `thead`, `tbody`, `tr`, `th`, `td`  
- **Sectioning tags:** `header`, `section`, `footer`

### 🔸 Internal Navigation Example
```
<a href="#skills">Go to Skills</a>
<section id="skills"> ... </section>
```

### 🔸 Self-Closing Tags
- `<br>`
- `<hr>`
- `<img>`
