# 🎨 Day 4 — CSS Components Challenge

## 📌 Goal
Build **3 CSS components** using only HTML + CSS:
1. Profile Card  
2. Notification Alert  
3. Product Card with Hover Effect  

The aim was to practice:
- Width / Height  
- Padding / Margin  
- Border & Border-Radius  
- Centering methods  
- Component-based layout  
- Hover transitions

## 🧪 Extra Learnings
- Correct usage of `width` and `height`.
- Why `*{ margin:0; padding:0 }` affects layout.
- Importance of using single wrapper `<div>` instead of multiple `<section>` tags.
- Centering cards using `margin: 0 auto;`.
- Using consistent fonts and spacing.
