## ✅ **Task 3 — Arrays Super Warm-up**
Create an array of 5 numbers.  
Perform:
- push  
- pop  
- splice  
- indexOf  
- map (divide every value by 2)  
- filter (keep numbers > 10)  
- find (find first number divisible by 3)  
- some (check if any value > 100)

Print results of each step.
