# 🚀 Day 13 – Mini Project: Counter App

Today you will build your first real interactive JavaScript project —  
a fully functional **Counter App** that updates UI instantly using DOM.

This project must include:

---

## ✅ 1. Counter Display
Create a big number in the center:

```
0
```

It will change dynamically as user interacts.

---

## ✅ 2. Three Main Buttons

### ✔ **Increment**
When clicked → counter increases by **+1**

### ✔ **Decrement**
When clicked → counter decreases by **–1**  
(But don’t allow it to go below 0 unless BONUS mode is ON)

### ✔ **Reset**
Sets the counter back to **0**

---

## ✅ 3. BONUS Button (Optional but OP)
Create a **Double Mode** toggle button:

### “Double Mode: ON”  
→ Increment becomes +2  
→ Decrement becomes –2  

### “Double Mode: OFF”  
→ Normal mode returns

This teaches:
- state management  
- conditionals  
- class toggling  
- dynamic UI changes

---

## ✅ 4. Change Color Based on Value
Use DOM style change:

- If counter > 0 → text becomes **green**
- If counter == 0 → text becomes **white**
- If counter < 0 → text becomes **red** (only if you allow negative)

---

## ✅ 5. Add a Cool Animation (Optional)
When number updates:
- Add a quick scale animation
- Or fade animation

(either CSS animation or JS class toggling)

---

## 🎯 Project Goal
By finishing this project you will understand:

- DOM selection  
- Event listeners  
- Updating text with JS  
- UI state  
- Conditionals  
- Bonus: animations + dynamic buttons

This is REAL FRONTEND DEV WORK.
