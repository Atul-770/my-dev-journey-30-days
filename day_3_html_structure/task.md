# 🎯 Goal of the Day  
Build a **complete and professional HTML webpage layout** using only HTML — *no CSS, no JavaScript*.  
This layout becomes the base for styling on **Day 4 (CSS)**.

---

# 🧩 What You Must Build

### 🏗️ **1. Header + Logo + Navigation**
- Website title or logo  
- Navigation menu with anchor links  
- Smooth structure using `<header>` and `<nav>`

---

### 🎬 **2. Hero Section**
A bold introduction at the top of the page:
- Heading  
- Intro paragraph  
- Call-to-action button  

---

### 📖 **3. About Section**
Write 2–4 lines describing yourself or your project.

---

### 🛠️ **4. Services Section**
Create at least **3 service cards**:
- Use `<div>` for each service  
- Title + description inside each  

---

### 🗣️ **5. Testimonials Section**
Use:
- `<figure>`  
- `<blockquote>`  
- `<figcaption>`  

This makes the page feel *real* and professional.

---

### ❓ **6. FAQ Section**
Use:
```html
<details>
  <summary>Question?</summary>
  Answer goes here.
</details>
```

This gives interactivity even without JavaScript.

---

### 📬 **7. Contact Section**
A simple form:
- Name  
- Email  
- Message textarea  
- Send button  

---

### 👥 **8. Team Section**
Show 3 members with:
- Image  
- Name  
- Role  

---

### 🧱 **9. Footer**
Include:
- Copyright  
- Back to top link  

---

# ✔️ Final Expected Result
A fully structured webpage with clear sections, semantic HTML, and working internal navigation.
