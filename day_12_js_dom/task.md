# 🚀 Day 12 – DOM Manipulation Tasks

Today your webpage becomes ALIVE.  
Your mission is to wake up the DOM using JavaScript.

---

## ✅ Task 1 — Change Text on Button Click
When the user clicks **Get Started**, change the hero `<h1>` to:

**“Welcome to the Monkey Kingdom!”**

---

## ✅ Task 2 — Toggle Dark Mode
Create a button (or repurpose Sign In) that toggles the entire page between:

- Light Mode  
- Dark Mode  

Hint: toggle a CSS class on `<body>`.

---

## ✅ Task 3 — Change Image Dynamically
On clicking **Learn More**, replace the monkey image with ANY other image link.

---

## ✅ Task 4 — Highlight All Card Titles
On page load, change all `.c-content h3` headings to BLUE.

---

## ✅ Task 5 — Hover Effect via JS
When hovering over any card (`.c1`):

- Add a shadow of `0 0 20px blue`
- Remove it when hover ends

---

## ✅ Task 6 — Console Event Tracker
Every time ANY nav link is clicked,
log to console:  
**“You clicked on NAV: Home”**

---

## 🔥 BONUS (Only if you want MAX grade)
Make a button that:

- adds a NEW card dynamically  
- with image + text  
- inserted into `.card-cont`
